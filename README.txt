Achtung: Wenn das Projekt aus diesem GitHub-Repository bezogen werden soll, müssen folgende Punkte beachtet werden:
- In diesem Repository wird Git LFS (Large File Storage) verwendet. Damit alle Dateien korrekt funktionieren, muss das Projekt zwingend über "git clone" heruntergeladen werden und Git LFS muss vorher bzw. anschließend initialisiert werden.
- Ein einfacher Download als ZIP über GitHub kann zu Problemen führen, da die von Git LFS verwalteten Dateien dabei nicht korrekt übernommen werden.
